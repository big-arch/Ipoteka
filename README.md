# Наши финансы

PWA без сборки и библиотек: ближайший платёж и остаток по всем ипотекам, помесячный график, досрочка по каждой ипотеке (в срок / в платёж / в платёж, но платить как раньше), бюджет семьи с планом «подушка → самая дорогая ставка → следующая» и лайфхаки.

**Личные данные в коде не хранятся.** Суммы и даты лежат только в IndexedDB браузера, а копия делается через «Данные → Скачать копию». Файлы копий (`ipoteka-*.json`) внесены в `.gitignore`. Если выложить приложение на GitHub Pages, публичной будет только пустая программа.

## Запуск на компьютере

```
node server.cjs
```
Откройте http://127.0.0.1:5177/

## Как перенести данные на телефон

На компьютере: «Данные → Скачать копию». Отправьте файл себе (например, в «Избранное» Telegram). На телефоне откройте приложение и нажмите «Загрузить копию». Чтобы поставить приложение на телефон, в браузере выберите «На главный экран».

## Как вносить кредиты

| Поле | Новый кредит (сразу после выдачи) | Старый кредит (уже платится) |
|---|---|---|
| Остаток долга / на дату | сумма кредита, дата выдачи | остаток после последнего платежа, дата этого платежа |
| Сколько платежей осталось | всё число платежей по договору | оставшееся число платежей (есть в графике банка) |
| Дата следующего платежа | первый платёж | следующий платёж |
| Платёж по договору | аннуитет из договора | текущий платёж |
| Первый платёж — только проценты | да, если так в графике Сбера | нет |

## Как считается

- Аннуитет: `платёж = долг × r / (1 − (1 + r)^−n)`, где `r` — ставка / 12.
- Проценты по умолчанию начисляются по дням, по фактическому числу дней (365 или 366), как в Сбере. Переключатель «ставка / 12» нужен для упрощённой проверки.
- Досрочка, внесённая в дату платежа, применяется после него. Внесённая между платежами сначала начисляет проценты до своей даты.
- «Уменьшить платёж» пересчитывает аннуитет на оставшиеся платежи, «уменьшить срок» сохраняет платёж.

**Сверено с графиком платежей Сбера построчно:** все 361 платёж нового кредита совпадают по датам, процентам и остатку (расхождение округления не больше 4 копеек). День 1 января банк относит к новому году, а последний платёж ставит на дату окончания срока — оба правила учтены.

**Проверено на реальных договорах Сбера:** аннуитет и первый платёж «только проценты» совпадают с договором до копейки, а помесячные остатки старого кредита за полгода сходятся с кредитной историей НБКИ до копеек. Если первый платёж состоял только из процентов, последний платёж по расчёту получается примерно двойным. Сверьте его с графиком в СберБанк Онлайн: банк может распределять этот остаток иначе.
